## ✅ Example (delete this part)

1. **App name:** ReadTrack
2. **Team:** Sara (lead), Omar (backend), Lina (design), Yusuf (testing)
3. **Problem:** Students forget which books they've read and can't see their progress toward the yearly reading goal.
4. **Users:** Students. No admins.
5. **Must-have:** add, edit and delete books; mark a book as reading or finished; rate finished books from 1–5; a progress bar toward a yearly goal (the user sets the goal); search books.
6. **Nice-to-have:** a public "Top rated books" page that shows the average ratings across all users.
7. **Data:** Book: title, author, pages, status (want to read / reading / finished), rating 1–5 (only if finished), notes. User: yearly goal (number).
8. **Private/shared:** Books are private. Only the "Top rated" page shows combined averages, with no usernames.
9. **Pages:** Home, Sign up, Log in, My books, Add/Edit book, Settings (goal), Top rated.
10. **Look:** Main colour #0d9488 (teal). Clean and friendly.
11. **Other:** Show the progress like "7 / 20 books (35%)".
